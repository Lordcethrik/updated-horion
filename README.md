# NY 9:30 Anchored VWAP (TradingView / Pine Script v6)

`ny_anchored_vwap.pine` draws a VWAP that resets every day at the 9:30 AM ET New York open and runs until the 4:00 PM close.

## Usage
Open TradingView's Pine Editor, paste in the whole file and click **Add to chart**. It works best on intraday charts (1–15 minutes).

Settings: the session time, whether to keep the line after 4:00 PM, and the line color and width.
